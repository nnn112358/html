X Video Downloader

X（旧 Twitter）の投稿 URL を貼り付けると、含まれる動画・GIF を解析して保存できます。

「保存」はブラウザ内で取得してからダウンロードします。失敗する場合は「開く」で直接リンクを開き、右クリックから「名前を付けて保存」してください。

対応 URL と仕組み
  • x.com / twitter.com / mobile.twitter.com / fxtwitter.com / vxtwitter.com の /status/ID 形式
  • 投稿 ID だけの入力（数字のみ）も可
  • 解析には公開 API（api.fxtwitter.com、予備として api.vxtwitter.com）を利用します。鍵付き・削除済み投稿は取得できません。
  • ダウンロードするコンテンツの権利は投稿者に帰属します。私的利用の範囲でお使いください。
