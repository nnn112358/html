# TW Video Downloader

X（旧 Twitter）の投稿 URL を貼り付けると、含まれる動画・GIF・画像を解析してブラウザから保存できる、単一 HTML ファイルのツールです。

サーバーやビルドは不要で、`x-video-downloader.html` をブラウザで開くだけで動作します。

## 使い方

1. `x-video-downloader.html` をブラウザで開く
2. X の投稿 URL（例: `https://x.com/user/status/1234567890`）を入力欄に貼り付ける
   - 「貼り付け」ボタンでクリップボードから入力して即解析することもできます
3. 「解析」を押す
4. 表示されたメディアの「保存」でダウンロード、または「開く」で直接リンクを新しいタブで開く

### URL パラメータで自動解析

クエリに `?url=` または `?id=` を付けて開くと、起動時に自動で解析します。

```
x-video-downloader.html?url=https://x.com/user/status/1234567890
x-video-downloader.html?id=1234567890
```

## 対応する入力

- `x.com` / `twitter.com` / `mobile.twitter.com` / `fxtwitter.com` / `vxtwitter.com` / `fixupx.com` / `twittpr.com` の `/status/ID` 形式の URL
- 投稿 ID のみ（数字だけ）の入力

## 機能

- 動画・GIF は画質（解像度・ビットレート）ごとのバリアントを一覧表示し、任意の画質を選んで保存
- 画像は原寸（`name=orig`）で保存
- 投稿者名・本文・元投稿へのリンクを表示
- ダウンロード中の進捗をプログレスバーと割合で表示
- 保存に失敗した場合は自動で新しいタブを開き、右クリックから保存できるようフォールバック
- ファイル名は `ハンドル名_投稿ID_解像度p.mp4` / `ハンドル名_投稿ID_連番.拡張子` の形式
- OS の設定に応じてダークモードに自動対応
- スマートフォン幅にも対応したレスポンシブレイアウト

## 仕組み

解析には公開 API を利用します。

| 優先順位 | API | 用途 |
| --- | --- | --- |
| 1 | `api.fxtwitter.com` | 主。複数の画質バリアントを取得 |
| 2 | `api.vxtwitter.com` | 予備。1 つ目が失敗したときに使用 |

取得した JSON を共通形式に正規化してから表示しているため、どちらの API で取得しても同じ UI で扱えます。

## 制限事項

- 鍵付き（非公開）アカウントの投稿、削除済みの投稿は取得できません
- 外部 API に依存しているため、API 側の仕様変更や停止で動作しなくなる可能性があります
- ブラウザ内で `fetch` して保存する方式のため、CORS の制限によって直接保存できない場合があります。その場合は「開く」から手動で保存してください
- 「貼り付け」ボタンはクリップボード読み取り権限が必要です（許可されない場合は手動で貼り付けてください）
